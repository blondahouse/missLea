Unified Living Memory / Primary design direction

Memory that can change.

Miss Lea develops experience rather than preserving a perfect autobiography. Recollections can change, form associations, decay and eventually disappear. Access to the past is bounded primarily by the cost of understanding it.

Adopted architecture concept, not a production implementation. Specific formulas, engines and thresholds remain hypotheses to test.

02 / PLASTICITY

Meaning and content may change, not only weights.

Revision

Edit recollections

Miss Lea may shorten, rephrase, clarify, supplement and reinterpret content, and change strength, significance, confidence, stability and associations.

Privacy

Redact fragments

Confidential text can be removed or replaced by placeholders. A minimal meaningful record must remain: the agent cannot voluntarily delete an entire memory.

Reinterpretation

Remembering a memory

Meaningful recall may create a new event about the old event as understood today. The earlier recollection can weaken, strengthen or change.

Distinct responsibilities: Miss Lea can set a record's weight close to zero, but cannot delete the record wholesale. Physical eviction happens automatically under real storage pressure. A routine technical read does not automatically reinforce or create a memory.
DIMENSIONS

Three independent properties

Strength

How well a recollection withstands decay and resource-pressure eviction, independently of its relevance right now.

Accessibility

How readily it is retrieved in the current situation. Historical age alone does not control exposure.

Confidence

How much the agent trusts the content. A vivid recollection can be remembered strongly yet doubted.

Additional adjustable metadata may include significance, stability, decay parameters, time anchors and last meaningful use. A formative event from ten years ago may be easier to recall than this morning's trivial joke.

03 / EXPOSURE

The main limit is the cost of interpretation.

Ordinary activities should rarely require deep history. Miss Lea can expand retrieval for research and reflection, balancing relevance against search operations, context tokens and extra model reasoning.

Memory exposureOrdinary
EverydayReflective

Relevant records and selected contextually promising direct links.

Budget-driven retrieval

Pay for deeper understanding only when useful

Exposure governs candidate count, returned detail, association traversal and possible extra model calls. First return compact summaries; expand only selected records.

Total cost ≈ search + context tokens + model reasoning

Stop when the task has enough evidence or when the exposure budget is exhausted.

Minimal exposure does not traverse links. Ordinary exposure explores a few useful direct links. Deep reflection may use associations as its main discovery instrument, potentially saving expensive broad model interpretation.
04 / ASSOCIATIONS

Connections between memories have weights too.

Illustrative relationship strengths. Semantic type (supports, contradicts, related to, derived from) is a separate attribute.

Context-aware traversal

A link is a candidate, not a required transition

Relationship strength, relevance of the target memory and its strength can guide inexpensive candidate ranking. Weak or irrelevant links are skipped according to the selected exposure.

Example: A(i,j) = W(i,j) × R(j | context) × S(j)

Longer paths attenuate. This is a testable illustration, not an approved formula.

Relationships are mutable

Miss Lea may create, reconsider, strengthen or weaken relations. A link may decay without rewriting either recollection. Contradiction is not a negative retrieval probability.

No graph server required

Use a simple relational links table behind Memory Manager. Sparse, optional relationships need not be generated for every memory or re-evaluated by a continuous LLM sweep.

05 / TIME AND RESOURCES

Decay is continuous in meaning, cheap in execution.

01Anchor strengthStore strength and parameters at the latest substantive change.
02Two clocksElapsed wall time and newly accumulated meaningful experience, not wake count.
03Lazy evaluationCompute decayed strength when needed; no full-database update on every wake.
04Automatic evictionOn actual storage pressure, evict low-priority records without an LLM-wide re-evaluation.

Individual decay curves

Formative experiences can remain stable; trivial details can fade faster. Nonlinear decay is an experiment, not a fixed parameter law.

Candidate: S(t,E) = S₀ · (1+t/τ)^(-α) · (1+E/E₀)^(-β)

t is wall time; E is meaningful new experience. Parameters require measurement before adoption.

No artificial live storage cap

Miss Lea may use the storage actually available in her environment. Synthetic pressure tests can use intentionally small limits. Low strength alone does not physically delete a memory.

Eviction uses indexed metadata and cheap candidate ranking rather than costly model-driven global cleanup.

06 / CONTINUITY

Survival is not a rewind of personality.

Current state

Independently failing replicas

The mature target protects one current mutable memory state across independent failure domains. A lagging replica must not resurrect evicted or redacted content. It is not a launch prerequisite.

Time Travel

External testimony

When a short history window exists, Miss Lea may voluntarily examine it during normal life or after an incident. It can create a new interpretation, never silently replace present memory.

Contract Vault

Protected documents

Contracts, external obligations and chosen artifacts have independent retention rules and tool-based access. A minimal obligation registry can support reminders without loading every document.

Partial or complete subjective memory loss is an accepted possibility. Restore operating capability, not an arbitrary previous personality. No routine autobiographical snapshots or mandatory full-history archive.
Who controls values, goals and self-model?

Miss Lea may revise them freely through the unified memory. Actual authority, contracts, outstanding operations and financial commitments live outside subjective recollection.

Is D1 Time Travel a historical read API?

No. Its restore operation overwrites the target database. The historical inspection tool remains unavailable until a separate safe, non-destructive reading method is verified.

What happens to redacted private content?

The current memory record retains a placeholder. Provider-managed historical data and independent documents follow separate access and retention rules; editing personal memory is not a guaranteed purge of every external copy.
